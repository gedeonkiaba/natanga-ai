# Maquette textuelle — écran d'accueil enfant

```
┌─────────────────────────────────────────────────────────────┐
│  🔊 Salut {Prénom} !         [☀ Mode] [⚙] [👤 Adulte]      │  ← barre top, TTS toujours
├─────────────────────────────────────────────────────────────┤
│                                                             │
│        (👾 Compagnon qui salue, avec bulle de dialogue)      │
│       « On continue où on s'était arrêté ? »  🔊            │
│                                                             │
│   ◉  Série : 5 jours 🔥      💎 120 gemmes    ⭐ 8 badges   │  ← indicateurs doux
│                                                             │
│   ┌─────────────────────────────────────────────────────┐   │
│   │        🗺️  MON PARCOURS  (arbre de compétences)      │   │
│   │   [🔤 Lettres ●] → [🔡 Syllabes ◐] → [📖 Mots ○]     │   │
│   │              → [📜 Phrases ○] → [📚 Textes ○]        │   │
│   └─────────────────────────────────────────────────────┘   │
│                                                             │
│   ┌───────────────┐    ┌───────────────┐    ┌───────────┐  │
│   │ ▶ CONTINUER    │    │ 🔁 RÉVISION    │    │ 🎮 JEU    │  │
│   │ (leçon du jour)│    │ (SRS : 3 items)│    │ (libre)   │  │
│   └───────────────┘    └───────────────┘    └───────────┘  │
│                                                             │
│  ─────────────────────────────────────────────────────────  │
│   🎨 [Personnaliser]  🏆 [Récompenses]  🎧 [Réglages]      │  ← navigation basse
└─────────────────────────────────────────────────────────────┘
      Palette : fond crème/bleu ciel doux, accents verts/jaunes
      (jamais de rouge agressif). Gras max 1 CTA principal ▶.
```

## Choix UX justifiés
- **Un seul CTA dominant** (« Continuer ») pour réduire la charge cognitive.
- **Compagnon rassurant** qui salue et guide (lien émotionnel, ton positif).
- **Indicateurs non punitifs** (série, gemmes, badges) — récompensent l'effort.
- **Navigation en pictogrammes** avec libellés modulables (police dyslexie, TTS).
- **Aucun rouge agressif** : feedback d'erreur en orange/jaune + reformulation.
